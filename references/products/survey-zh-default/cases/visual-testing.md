# 视觉或概念测试

## 多方案视觉测试

**适用**：比较多个视觉、布局、材质或概念方案的理解、匹配和偏好。

**核心结构**：

```text
目标人群和品类经验
→ 刺激材料说明
→ 方案随机或平衡展示
→ 单方案理解和评价
→ 方案间直接比较
→ 高低分原因
→ 首选和可接受方案
```

**关键设计**：

- 固定刺激材料尺寸、展示时间、设备和背景条件。
- 单方案评价优先于方案间比较，降低直接对比对绝对评价的污染。
- 样本、时长和负担不允许每人看全部方案时，使用区组或不完全设计。
- 偏好不自动等于更高理解、可用性或购买行为。

## 刺激物说明的写法

示例（人工构造）：

```markdown
##### V1.【方案展示】【ALL】接下来会依次展示 4 张锁屏设计图，每张图展示 5 秒后可以作答。请把屏幕亮度调到较高，并竖屏查看。【说明】

程序说明：4 张图随机顺序出示；每张图单独一页；5 秒后显示作答区。
```

## 常见错误

| 错误 | 后果 | 改法 |
|---|---|---|
| 新设计永远放在位置 A | 位置效应和新设计效应混在一起 | 位置随机或平衡 |
| 说明里写“方案 A 展现了新设计的特征” | 透露研究假设 | 只写展示条件，不评价方案 |
| 喜好用“1 = 非常不喜欢”，维度评分用“1 = 非常好” | 方向相反，分析和作答都会出错 | 全卷方向一致 |
| 视觉效果只用文字描述 | 受访者无法判断 | 用图片或短视频 |
| 卷首写“约 3 分钟”，却要为十几张图逐张打分和追因 | 时长承诺失实，后半段答案敷衍 | 按受访负担估算时长；图多时分组或不完全设计 |
