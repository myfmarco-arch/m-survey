# 购买决策

## 耐用产品购买决策

**适用**：理解最近完成购买的用户如何识别需求、对比方案并形成选择。

**核心结构**：

```text
购买时间和决策角色
→ 旧产品状态和购买触发
→ 考虑范围
→ 信息渠道和触点
→ 关注因素
→ 相对取舍
→ 最终选择原因
→ 购后体验和反思
```

**关键设计**：

- 区分购买者、主要决策者和实际使用者。
- 先追溯实际考虑集，再询问因素和取舍。
- 将当时的购买动因与购后的体验评价分开。
- 回顾性自报可能存在记忆和合理化偏差，不写成完整真实决策过程。

## 常见错误

| 错误 | 后果 | 改法 |
|---|---|---|
| 共同决策的人直接终止 | 丢失大部分真实购买者 | 区分角色；非主要决策者跳过决策模块，继续答使用模块 |
| 品牌列表的合并口径与上一波不同（某品牌是否含子品牌） | 品牌份额不可比 | 沿用上一波口径；改变时按跨波次可比性标注 |
| 放弃原因列表缺少价格和品牌 | 强制归因到产品体验 | 列表覆盖产品、价格、品牌、渠道和服务 |
| 用“最能打动您”的假设问题代替实际经历 | 高估功能吸引力 | 先问实际比较过什么、最后为什么选它 |
