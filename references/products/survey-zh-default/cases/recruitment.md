# 访谈招募与甄别

## 复杂经验用户招募

**适用**：招募需要满足多个设备、行为、经验和配额条件的定性访谈参与者。

**核心结构**：

```text
年龄和市场资格
→ 设备、产品或服务资格
→ 具体行为频率
→ 关键任务经验
→ 开放题经验验证
→ 时间和参与意愿
→ 联系方式
```

**关键设计**：

- 每个招募条件都对应可作答、可判定的题目。
- 使用具体行为和事件验证经验深度，不只使用自我评价。
- 区分结构配额和研究比较配额。
- 联系方式在明确用途和自愿意愿后收集，并与问卷答案分离保存。
- 招募问卷只用于甄别，不将便利招募样本当作总体画像。

## 常见错误

| 错误 | 后果 | 改法 |
|---|---|---|
| 用“是 / 否”直接问是否使用目标产品 | 目标外露，容易作假 | 把目标产品混在同类列表中，没选中才终止 |
| 要排除某类流失原因，却只用多选题 | 无法识别主要原因 | 多选后追问“最主要的一个原因” |
| 版本选项写了不存在的版本 | 受访者困惑，资格判断出错 | 版本列表按发布记录核对；给查看路径 |
| 开放题可以跳过，却用来判断表达能力 | 筛不出表达能力 | 关键开放题设为必答，并给作答方向 |
