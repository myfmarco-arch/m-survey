# 访谈招募与甄别

## 复杂经验用户招募

**适用**：招募需要满足多个设备、行为、经验和配额条件的定性访谈参与者。

## 先写招募需求表

写题前先把每个招募条件写成可追溯的记录，格式见 [问卷模板](../templates.md) 的“招募与甄别问卷”。不要从“想问什么”开始列题。

每个条件都必须能追溯到题号、选项和处理方式。没有明确用途的信息不应加入问卷。

**核心结构**：

```text
招募需求表
→ 直接甄别
→ 事后判断与软配额
→ 信息预采集
→ 时间和参与意愿
→ 独立联系方式
```

## 三类招募题

- **直接甄别题**：验证硬资格或硬配额。不符合时可以即时终止，并记录“不符合条件”。
- **事后判断题**：收集主观判断、经历深度或软配额信息。默认不即时淘汰，供人工综合筛选或后续配额控制。
- **信息预采集题**：为研究、执行、配额或后续联系收集信息。每题都要写明用途，不因信息收集本身而淘汰。

软配额和研究比较配额不是硬资格。只有项目明确把某项改为硬条件时，才可以即时终止。配额已满和不符合条件要分开记录。

**关键设计**：

- 每个招募条件都对应可作答、可判定的题目。
- 使用具体行为和事件验证经验深度，不只使用自我评价。
- 区分结构配额和研究比较配额。
- 题目角色、配额类型、处理方式和题号相互对应，能从招募需求表追溯到问卷。
- 卷首语说明参与方式、时间成本、激励和后续流程，但不暴露具体筛选条件、目标品牌或研究假设。
- 联系方式在说明访谈形式、时长、激励、后续联系和信息使用范围，并取得明确同意后收集；优先放入独立表单或独立数据表。
- 招募问卷只用于甄别，不将便利招募样本当作总体画像。

## 常见错误

| 错误 | 后果 | 改法 |
|---|---|---|
| 用“是 / 否”直接问是否使用目标产品 | 目标外露，容易作假 | 把目标产品混在同类列表中，没选中才终止 |
| 要排除某类流失原因，却只用多选题 | 无法识别主要原因 | 多选后追问“最主要的一个原因” |
| 版本选项写了不存在的版本 | 受访者困惑，资格判断出错 | 版本列表按发布记录核对；给查看路径 |
| 开放题可以跳过，却用来判断表达能力 | 筛不出表达能力 | 关键开放题设为必答，并给作答方向 |
| 把软配额写成即时终止条件 | 错误排除仍有研究价值的样本 | 标为事后判断，写明后续筛选或配额处理 |
| 事后判断题和硬资格题混在一起 | 无法解释淘汰原因和样本结构 | 在招募需求表和题目标签中区分角色 |
| 未取得同意就收集联系方式 | 联系目的不透明，隐私风险增加 | 先说明后续流程并取得同意，再进入独立联系方式表单 |
| 对隐私作出“绝不外泄”等绝对承诺 | 承诺无法由问卷设计保证 | 说明用途、访问范围、保存期限和处理方 |
| 预采集没有明确用途 | 增加负担，难以决定是否保留 | 删除，或写明研究、执行、配额或联系用途 |
