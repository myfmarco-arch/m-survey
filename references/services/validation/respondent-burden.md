# 受访负担

本服务估算问卷时长，检查手机端作答负担。交付完整问卷或修订问卷前执行。

触发条件：交付完整问卷、修订问卷，或用户给出目标时长。

## 为什么需要估算

卷首写的时长如果没有依据，常常低估。低估会提高中途退出率，后半部分的答案也更敷衍。时长承诺要像样本量一样有参数和计算。

## 估算方法

每道题的时间 = 阅读时间 + 作答时间。

- 阅读时间 = 题干、选项和矩阵行的字数 ÷ 阅读速度。
- 作答时间按题型取值；矩阵按行计，排序按需要排出的位置计，开放题区分必答和选答。
- 参数见 [时长估算参数](../../modules/knowledge/timing-parameters.yaml)。这些数值是起始假设，没有校准前，在交付物中写明“按起始参数估算”。

估算两条路径：

| 路径 | 计算 | 用途 |
|---|---|---|
| 典型路径 | 每题时间 × 预计看到这道题的受访者比例；循环题 × 预计循环次数 | 卷首语承诺的时长 |
| 最长路径 | 所有题都显示，循环取最大次数 | 说明哪些人会明显超时 |

预计比例和循环次数写在规格的 `expected_share`、`expected_loops` 中。没有填写时，脚本按参数文件的默认值计算，并在结果中列出用了默认值的题目。默认值本身是假设。

有代码执行环境时运行：

```bash
python scripts/estimate_duration.py spec.yaml
```

## 交付格式

| 项目 | 内容 |
|---|---|
| 典型路径 | 约 X 分钟 |
| 最长路径 | 约 Y 分钟；会遇到最长路径的人群 |
| 参数来源 | 起始参数，或已用某次历史问卷校准 |
| 最耗时的题目 | 前 5 题及各自秒数 |
| 删减清单 | 超过目标时长时给出：删什么、省多少时间、损失哪个研究问题 |

卷首语承诺的时长不低于典型路径，一般也不高于最长路径。不写“约 10 分钟”却交付一份典型路径 14 分钟的问卷；也不为了保险把 4 分钟的问卷写成 10 分钟，那会劝退一部分受访者。

## 校准

有历史问卷和平台记录的完成时长时：

1. 用同一套参数估算历史问卷的典型路径。
2. 校准系数 = 实际中位完成时长 ÷ 估算典型时长。
3. 把系数写进参数文件的 `calibration.factor`，并在 `calibration.basis` 记录用了哪份问卷、多少样本。
4. 用两份以上问卷校准时，取系数的中位数；系数差异很大时，说明问卷类型不同，分开维护参数。

## 手机端负担

| 情形 | 默认阈值 | 处理 |
|---|---|---|
| 评分矩阵行数多 | 超过 10 行 | 拆成两屏，或改为只显示上一题选过的行，或改为循环单题 |
| 选项多 | 普通选项超过 15 项 | 分组展示，或先选大类再选细项 |
| 说明文字长 | 单题超过 150 字 | 拆短、配图，或单独一页说明 |
| 必答开放题多 | 超过 2 道 | 改为选答，或只保留最关键的一道 |

阈值是官方默认值，团队可以在自己的参数文件中修改。

## 规则

| rule_id | 检查 | 默认严重程度 | 脚本可检 |
|---|---|---|---|
| `burden.duration-estimated` | 完整问卷给出典型路径和最长路径时长，并写明参数来源 | `warning` | 是 |
| `burden.over-target` | 典型路径超过目标时长时给出删减清单 | `warning` | 是（需填写 `meta.target_minutes`） |
| `burden.unsupported-duration` | 卷首语承诺的时长不低于典型路径估算，一般不高于最长路径 | `warning` | 是（低于典型路径的 80% 时报告；需填写 `meta.estimated_minutes`） |
| `burden.matrix-size` | 评分矩阵行数不超过阈值，或已拆分、只显示相关行 | `warning` | 是 |
| `burden.long-list` | 普通选项数超过阈值时分组或分两步 | `info` | 是 |
| `burden.long-text` | 单题文字超过阈值时拆短或配图 | `info` | 是 |
| `burden.open-text-count` | 必答开放题不超过 2 道 | `info` | 是 |
