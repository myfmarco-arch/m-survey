# 数据质量控制

本服务确保回收的数据可信：受访者符合条件、认真作答、没有重复或伪造资格。交付可投放的完整问卷或修订问卷前执行。

触发条件：交付完整问卷、修订问卷，或审核问卷时用户关心数据质量。

## 先看渠道

不同渠道的风险不同。问卷规格中用 `meta.channel` 记录渠道。

| 渠道 | `meta.channel` | 主要风险 | 默认组合 |
|---|---|---|---|
| 自有用户：App 内、系统推送、邮件名单 | `in_app`、`email` | 自选择；活跃用户偏多 | 逻辑一致性、最短时长、直线作答、开放题检查；指令题按需 |
| 外部样本库 | `panel` | 职业受访者、伪造资格、快速乱答 | 行业排除、近期参与排除、指令题、逻辑一致性、最短时长、直线作答、开放题检查 |
| 社区、社交媒体、公开链接 | `community`、`social` | 重复作答、为奖励刷答、圈层偏差 | 同外部样本库，并加重复作答控制 |
| 拦截、电话、面访 | `intercept`、`phone`、`in_person` | 访员效应、社会期许 | 访员质控、录音或抽查回访；指令题通常不适用 |
| 公司内部员工 | `internal` | 立场偏差、了解研究目的 | 说明结果只代表员工；目的隐藏通常无效 |

## 甄别

- **行业排除**：外部样本和公开链接排除本行业、市场调研、广告公关从业者（受访者本人或直系亲属，按组织口径）。自有用户名单按需。
- **近期参与排除**：外部样本排除近期参加过同类调研的人。时间窗沿用组织或样本供应商口径；没有口径时写成假设。
- **隐藏研究目的**：外部样本的卷首只说明大类主题；目标品牌、目标功能混在同类选项中随机展示。隐藏的是研究假设和委托方，不是数据用途：数据用途、保存和联系安排仍按 [隐私基线](privacy-baseline.md) 告知。
- **终止原因分类**：记录不符合条件、配额已满和质量不合格三类，方便核算发生率和样本成本。

## 问卷内检测

| 类型 | 写法 | 注意 |
|---|---|---|
| 指令题 | “为确认您在认真阅读，本题请选择‘比较同意’。” 放在长矩阵中，或作为单独一题 | 首选。正确答案唯一、不需要专门知识 |
| 逻辑一致性 | 型号与价格区间、型号与系统版本、购买时间与使用时长、前后两次出现的同一事实 | 只用于客观事实；态度题的“正反表述”容易误伤认真作答的人 |
| 开放题质量 | 必答开放题检查乱码、重复字符、复制题干、与题无关 | 只把明显无效的作为剔除条件 |
| 常识题 | “以下哪个城市是中国的首都？” | 区分度低，只作补充，不作唯一检测 |

- 每份问卷的检测题不超过 2 道，措辞礼貌，不让受访者感到被怀疑。
- 检测题在规格中用 `quality` 字段标记，写明正确选项和处理方式（终止或标记）。
- 不把检测题放在甄别的第一题。

## 清洗规则

回收前写好，回收后不再根据结果调整。每条写明判定条件、处理方式和依据：

| 规则 | 判定条件示例 | 处理 |
|---|---|---|
| 作答过快 | 完成时长低于预设阈值。没有组织口径时，常见起始做法是取中位数的三分之一，并在方案中写明这是假设 | 剔除或标记复核 |
| 直线作答 | 行数较多的评分矩阵所有行同分 | 标记复核；不自动剔除，真实意见也可能一致 |
| 指令题答错 | 未选择指定选项 | 按事先规定终止或剔除 |
| 事实矛盾 | 交叉核验的事实不一致，例如型号的上市价格不在所选价格区间 | 剔除或标记复核 |
| 开放题无效 | 必答开放题为乱码、复制题干或与题目无关 | 标记复核；多项同时出现时剔除 |
| 重复作答 | 同一受访者多次提交 | 只保留第一次 |

重复作答控制如果需要记录设备标识、IP 或账号，触发 [隐私基线](privacy-baseline.md) 的数据关联规则。

规格中用顶层 `quality.cleaning_rules` 记录清洗规则。它们写进研究简报与方案的样本方案小节，不放进问卷文件；用 `render_markdown.py --cleaning-rules` 生成表格。

## 规则

| rule_id | 检查 | 默认严重程度 | 脚本可检 |
|---|---|---|---|
| `quality.screening-exclusions` | 外部样本和公开链接包含行业排除和近期参与排除；自有用户名单按需设置并说明 | `warning` | 否 |
| `quality.hidden-purpose` | 外部样本的卷首和甄别不暴露研究假设、目标品牌或目标功能；数据用途照常告知 | `warning` | 否 |
| `quality.attention-check` | 外部样本库、社区和公开链接至少有 1 道指令题或等效检测，并写明正确答案和处理方式 | `warning` | 是（需填写 `meta.channel`） |
| `quality.consistency-check` | 问卷中存在可交叉核验的客观事实时，至少设置一组一致性核验并写入清洗规则 | `info` | 否 |
| `quality.cleaning-rules` | 回收前写明清洗规则：判定条件、处理方式和阈值依据 | `warning` | 是 |
| `quality.respectful-check` | 检测题不超过 2 道、措辞礼貌、正确答案唯一，不以常识题作为唯一检测 | `info` | 是（数量） |
| `quality.terminate-reasons` | 终止原因区分不符合条件、配额已满和质量不合格 | `info` | 否 |
